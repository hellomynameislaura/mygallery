# My Gallery

A small React + Three.js portfolio experience by Laura Cunha.

## Setup

1. Install dependencies
   ```bash
   npm install
   ```

2. Run the development server
   ```bash
   npm run dev
   ```

3. Open the URL shown by Vite in your browser.

## Project Structure

- `index.html` — application entry point
- `src/main.jsx` — React app bootstrap
- `src/App.jsx` — main application shell
- `src/components` — UI and Three.js components
- `src/data/projects.js` — project content data
- `src/utils/device.js` — mobile detection helper
- `public/images` — add your project images here

## Notes

- Place your image files at `public/images/muzza.png`, `public/images/era.png`, and `public/images/entrelinhas.png`.
- If you want to use the 2D gallery on mobile devices, the app switches automatically.
